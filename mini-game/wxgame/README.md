# 打工人合成记 · 微信小游戏版

这是适配 **微信小游戏 runtime** 的版本（与 H5 版 `mini-game/index.html` 共享物理引擎和文案，但 UI / 输入 / 存储 / 分享 / 广告全部用 `wx.*` API 重写）。

## 项目结构

```
wxgame/
├── game.js                   # 入口（被 runtime 自动加载）
├── game.json                 # 游戏配置（竖屏、隐藏状态栏、网络超时）
├── project.config.json       # 开发者工具配置（含 appid 占位符）
└── src/
    └── main.js               # 全部游戏代码（物理 + 渲染 + 输入 + 平台桥接）
```

整个项目零依赖，纯原生 JS。

## 关键技术点

- **全 Canvas UI**：所有面板、按钮、分数框都在 canvas 上画，通过坐标命中测试响应触摸。runtime 没有 DOM。
- **逻辑/像素分离**：物理用 380×540 设计坐标，渲染时按 `stageScale` 缩放到屏幕，触摸坐标反向换算回设计坐标。
- **续命懒加载**：结束面板始终显示「📺 看广告续命」按钮（除非已用过或已赢），点击时再走 `wx.createRewardedVideoAd` 的 `show → 失败重 load → 重 show` 兜底流程，加载中按钮置灰显示「加载中...」。adUnitId 占位为 `TODO_REPLACE_WX_AD_UNIT_ID`。
- **分享卡片图**：用 `wx.createCanvas()` 第二次调用得到的离屏 canvas 画 500×400 PNG（顶部头衔角色 + 工资 + "你能比我高吗"），`canvas.toTempFilePathSync` 拿到本地临时路径后传给 `wx.shareAppMessage` 的 `imageUrl`。右上角菜单分享和结束面板分享按钮都用同一张图。
- **触觉反馈**：`wx.vibrateShort` 区分轻 / 中 / 重——普通合成 `light`，新解锁职级 `medium`，CEO 以上和「财富自由 ×2」`heavy`。
- **`wx.setStorageSync` 持久化**：键名 `dgr_best`、`dgr_best_role`、`dgr_intro_seen`。
- **埋点经 `wx.reportEvent`**：事件名与 H5 版一致（`game_start`/`first_merge`/`reach_level`/`game_over`/`revive_*`/`share_*`），调试时 `GameGlobal.__DEBUG_TRACK__ = true`。

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（选「稳定版」）
2. 打开 → 「导入项目」→ 选择 `mini-game/wxgame/` 目录
3. 在 `project.config.json` 把 `TODO_REPLACE_WITH_YOUR_WX_APPID` 换成你的 **小游戏 appid**（注意是「小游戏」，不是「小程序」，前缀通常是 `wx`）
4. 模拟器中可直接玩；点「预览」扫码可在手机上玩

调试技巧：开发者工具 Console 输入 `GameGlobal.__DEBUG_TRACK__ = true` 后所有埋点事件会打印到控制台。

## 上线流程（重要：版号是最大的坑）

### 第 1 步 · 账号准备（1-3 天）

1. 注册：[mp.weixin.qq.com](https://mp.weixin.qq.com) → 选「**小游戏**」（不是小程序）
2. 主体认证：
   - 个人：免费，但**类目极受限**——休闲游戏类大多要企业主体
   - 企业：¥300/年，类目齐全
3. 拿到 appid，填入 `project.config.json`

### 第 2 步 · 资质材料（最耗时，并行做）

| 材料 | 怎么搞 | 时长 | 费用 |
|---|---|---|---|
| **软件著作权** | 自助申请走「中国版权保护中心」官方通道，或淘宝代办（搜「软著代办」） | 30-60 天 | ¥300-800 |
| **游戏版号（ISBN）** | 走出版集团 + 广电总局审批，必须代理 | **3-12 个月** | ¥1.5-3 万 |
| **隐私政策** | 写一份，托管到任意 HTTPS 站点 | 1 天 | 0 |
| **ICP 备案**（如有自有服务） | 阿里云 / 腾讯云后台 | 1-3 周 | 0 |

> ⚠️ 自 2024 年起微信小游戏对版号执行严格——**没版号几乎过不了商业化审核（即开广告）**。但提审上线本身可以先不带广告先跑，等版号下来再开 IAA。

### 第 3 步 · 开发者工具内配置

1. 点「详情」→ 「基本信息」：填游戏名「打工人合成记」、简介
2. 「上传」→ 写版本号（首次填 1.0.0）和说明
3. 进入 [mp.weixin.qq.com](https://mp.weixin.qq.com) 后台：
   - 「版本管理」可看到上传的版本，先「设为体验版」给团队/朋友扫码玩 7 天
   - 没问题点「提交审核」

### 第 4 步 · 提审前必填

- **类目选择**：游戏 → 休闲益智 → 消除类（合成类官方归这里）
- **隐私政策 URL**：填托管地址
- **运营人员 + 客服联系方式**
- **服务范围地区**：默认全国
- **审核说明**：附软著号 + 版号（没版号就先空着，可能被退）

### 第 5 步 · 审核（1-7 天）

常见拒审原因 + 对策：
- "未提供版号" → 走「轻量休闲游戏豁免通道」试试，或先纯单机无 IAA 提交
- "测试不充分" → 录一段全流程录屏附上
- "类目不符" → 改类目重提
- "包含广告但未声明" → 默认就是 IAA，要在审核说明里写

### 第 6 步 · 上线 + 流量主

- 审核通过点「发布」 → 立即可搜索可分享
- DAU 满 1000 → 后台「流量主」入口可申请开通广告位
- 申请通过后到流量主后台拿到 **真实 adUnitId**，替换代码里的 `TODO_REPLACE_WX_AD_UNIT_ID`，重新上传一版

## 常见问题

**Q: 体积限制？**
微信小游戏单包 4MB，分包 20MB。当前项目 < 30KB，毫无压力。

**Q: emoji 在某些 Android 设备上不显示？**
小游戏 runtime 的 `ctx.fillText` 对部分多 codepoint emoji（带 VS-16 选择子的）支持有限。代码已用单 codepoint emoji（如 🏝 而非 🏝️）规避。如仍有问题，可换成 PNG 资源贴图。

**Q: 续命广告位还没下来怎么办？**
没真实 adUnitId 时 `Ad.available()` 返回 false，结束面板自动不显示续命按钮，不影响整体玩法。

**Q: 数据怎么看？**
- 微信后台 → 数据分析（基础数据：访问、留存、分享）
- `wx.reportEvent` 自定义事件：需先在后台「数据助手」配置事件 ID 才会上报，否则只在本地 console 可见
