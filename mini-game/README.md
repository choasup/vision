# 合成大西瓜 🍉

一个单文件 HTML5 物理小游戏：水果掉下去，**同种相撞合成下一阶**，从樱桃一路凑到大西瓜。

## 玩法

- 鼠标移动 / 触屏拖动 → 选择落点
- 点击 / 空格 / 回车 → 丢下水果
- 同等级水果碰撞会合并成下一阶
- 任何水果长时间停在虚线之上 → 游戏结束
- 凑出 🍉 大西瓜 +500 分；两个大西瓜对撞 +1000 分

## 开始玩

```bash
# 任选一种
open mini-game/index.html              # macOS
xdg-open mini-game/index.html          # Linux
python3 -m http.server -d mini-game 8000  # 起本地服务，访问 http://localhost:8000
```

## 特性

- ⚛️ 自实现的简易刚体物理（重力、碰撞、摩擦、自旋），无任何依赖
- 🎯 危险线警告：水果停在线上方过久会变红、爆炸性动画提示
- 🎉 连锁合并触发 COMBO，分数倍率成长
- 💾 最高分自动保存（localStorage）
- 📱 鼠标 / 触屏 / 键盘 全平台支持，自适应屏幕
- 📦 单 HTML 文件，零依赖，离线可玩
